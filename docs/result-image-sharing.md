# 結算圖片分享

結算畫面提供「製作結算圖片」。在本機擷取結算卡為 PNG，預覽後再按「分享圖片」開啟系統分享，或按「下載 PNG」。保留原有文字分享與複製；取消分享不會自動下載。

只擷取明確標記的結算範圍，排除操作按鈕、連結、隱藏內容、聊天與邀請資料。捲動名次在副本展開，原畫面不改動。結果／語系改變與離開畫面時釋放預覽資源。

渲染器為同站靜態資產 html2canvas 1.4.1（MIT），第一次製作時才載入，無執行階段 CDN、圖片上傳或後端服務。系統是否可分享 PNG 由瀏覽器與裝置決定，無支援時可下載後自行分享。

驗證：`node tests/result-share.cjs`、`node tests/result-share-image.cjs`。圖片測試實際驗證 PNG 像素、完整捲動內容、檔案分享 payload、取消、下載、重試、舊結果隔離、資源釋放與四種視窗尺寸。原生分享面板以 API stub 驗證，實體手機跨 App 傳送另行驗收。
